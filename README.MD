# HandwrittenImageMiya - 簡単画像・PDF注釈ツール

## 概要

画像（PNG、JPG、BMP、GIF、WebP）やPDFファイル、さらにはパソコン画面のスクリーンショットをそのまま取り込み、矢印・吹き出し・文字・図形・マーカー・モザイク・連番スタンプ・注目枠などの注釈を素早く書き込んで相手にすぐ共有できるWindows向けデスクトップアプリです。
お仕事の資料作成や手順書作り、チャットやメールでの素早い説明・指摘に最適です。

## 主な機能

- 撮って・書いて・すぐ送れる最短フロー: ツールバーの「📸 画面撮影」で画面の好きな範囲をその場でキャプチャしてすぐ編集でき、描き終わったら「📋 画像コピー」を1クリックするだけでチャットやメール、Word・Excelへそのまま貼り付けて相手に送れます。
- 吹き出し（コールアウト）ツール: 「💬 吹き出し」を選んで指したい場所からドラッグしてコメントを入力するだけで、矢印のしっぽが付いた読みやすい角丸吹き出しを1発で作成できます。配置後も、しっぽの先端だけをつまんで指す位置を自由に動かせます。
- 注目スポットライト＆モザイク目隠し: 図形から「スポットライト」を選ぶと、指定した範囲だけ明るく浮かび上がらせて周囲を暗くできるため、相手に見てほしい場所が一瞬で伝わります。個人情報などは「モザイク」でドラッグするだけで簡単に隠せます。
- 連番スタンプ＆多彩な線・マーカー: クリックするだけで 1, 2, 3... と順番に丸数字を置ける「連番スタンプ」、直線・矢印・両矢印・曲線・半透明蛍光ペン（マーカー）、四角・角丸四角・丸/楕円・三角を備えています。線スタイルも「実線」「破線」「点線」から選べます。
- ワンクリックのクイックカラーパレット＆スポイト: ツールバー上段の8色パレットをクリックするだけで色ダイアログを開かずに1クリックで色を変えられます（右クリックで背景/塗色）。「💉 スポイト」を使えば画像上の任意の色を吸い取ってそのまま塗りに使えます。
- 切り抜き（トリミング）＆ドラッグ余白調整: 「✂️ 切り抜き」で必要な部分だけを素早くトリミングでき、「⏹️ 余白調整」で周囲の青いバーをドラッグして余白を広げたり戻したりできます。すでに描いた注釈も自動で位置補正されます。
- 定型文＆Ctrl+Enter対応の高速テキスト入力: テキスト入力画面に「ここを確認」「修正お願いします」「OK」「NG」「※注意」「削除」の定型文ボタンと入力履歴を備え、Ctrl+Enter でマウスを動かさずに即確定できます。配置済みの文字や吹き出しはダブルクリックですぐ書き直せます。
- 複数ページのPDFに完全対応: PDFファイルを開いてページを切り替えながら全ページに注釈を書き込め、元のページ構成を保ったまま1つのPDFとして保存できます。
- わかりやすいライトモード画面＆1キー切替: パソコンの設定に関わらず常に明るい見やすい画面で動作します。キーボードの1キー（V:選択、A:矢印、R:四角、T:文字、B:吹き出し、N:連番、M:モザイク、S:スポットライト、C:切り抜き、I:スポイト など）でツールを瞬時に切り替えられます。
- 検索できるヘルプセンター（F1）: ツール解説・ショートカット一覧・素早く伝える活用コツ・Q&Aをタブ分け＆キーワード検索で見やすく確認できます。
- やり直し・プロジェクト保存: 「戻る」（Ctrl+Z）や「進む」（Ctrl+Y）で何度でもやり直せます。「プロジェクト保存（.hwi）」を使えば、注釈を動かせる状態のまま保存して後日続きから編集できます。

## 動作環境

- Windows 10 / Windows 11（64ビット版）

## インストール・実行方法

特別なインストール作業は不要です。

1. 配布された HandwrittenImageMiya-v2.0.0.exe をパソコンの分かりやすいフォルダに保存します。
2. HandwrittenImageMiya-v2.0.0.exe をダブルクリックして起動します。

### 初回起動時に警告画面が表示される場合

Windowsの保護機能（Windows Defender SmartScreen）により、「WindowsによってPCが保護されました」という青い警告画面が表示されることがあります。これは未登録のアプリを初めて起動する際に出る標準のメッセージです。以下の手順でそのまま安全に起動できます。

1. 画面内の「詳細情報」をクリックします。
2. 右下に表示される「実行」ボタンをクリックすると、アプリが起動します。

※ 一度実行すると、2回目以降は警告が表示されなくなります。

## 基本的な使い方

1. 画像を用意する:
   - 画面をそのまま撮る: ツールバーの「📸 画面撮影」（Ctrl+Shift+A）を押して、画面上で欲しい範囲をドラッグします。
   - ファイルを開く: 「📂 開く」ボタンを押すか、画像・PDFファイルをアプリ画面へドラッグ＆ドロップします。
   - スクショを貼り付ける: クリップボードに画像がある状態で Ctrl+V（または「ファイル」→「クリップボードから新規作成」）を押します。
   - 白紙から描く: 「ファイル」→「新規キャンバス作成」を選ぶか、そのまま線や図形ツールを選ぶと自動で白紙キャンバスが開きます。
2. 素早く注釈を描く:
   - 吹き出し（B）: 指したい箇所からコメントを置きたい場所へドラッグし、文字を入力して Ctrl+Enter で確定します。
   - 矢印（A）・マーカー（H）・図形（R / O）: ドラッグで描きます。Shiftキーを押しながらドラッグすると、水平・垂直・45度やきれいな正方形・正円に揃います。
   - スポットライト（S）・モザイク（M）: 強調したい箇所や隠したい箇所を四角くドラッグするだけです。
   - 連番スタンプ（N）: 説明したい順番にクリックするだけで 1, 2, 3... と自動で番号が振られます。
   - 色を変える: 上段の8色クイックパレットを左クリックすると線・文字色、右クリックすると背景・塗色が1クリックで変わります。画像の色を真似したいときは「💉 スポイト」（I）を使います。
3. 切り抜く・微調整する:
   - 必要な部分だけ残すときは「✂️ 切り抜き」（C）で範囲をドラッグし、Enterキーまたは下の確定ボタンを押します。
   - 描いた注釈は「↖️ 選択/移動」（V）でドラッグ移動・ハンドルリサイズ、矢印キーで1px微調整（Shift併用で10px）ができます。文字・吹き出し・スタンプはダブルクリックですぐ編集できます。
4. 画面を拡大・移動する: Ctrlキーを押しながらマウスホイールを回すとカーソル位置を中心に拡大・縮小できます。拡大中に画面を動かすときは、スペースキーを押しながらドラッグ（または中ボタンドラッグ）で移動できます。
5. すぐ送る・保存する:
   - 相手にすぐ送る: 「📋 画像コピー」（Ctrl+Shift+C）を押して、チャットやメール・資料上で Ctrl+V するだけで完成画像をそのまま送信できます。
   - ファイルに保存する: 「💾 保存」（Ctrl+S）で上書き保存、「💾 名前を付けて保存」（Ctrl+Shift+S）で JPG / PNG / PDF として保存できます。
   - 後で修正できるように残す: 「📦 プロジェクト保存」（Ctrl+P）で .hwi ファイルとして保存してください。
