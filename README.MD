# HandwrittenImageMiya - 簡単画像・PDF注釈ツール

## 概要

画像（PNG、JPG、BMP、GIF、WebP）やPDFファイルを読み込み、文字・矢印・図形・マーカー・モザイク・連番スタンプなどの注釈を直感的に書き込めるWindows向けデスクトップアプリです。
お仕事の資料作成やマニュアル作り、写真・スクリーンショットへのメモ書きに最適です。

## 主な機能

- わかりやすいライトモード画面: パソコンの設定に関わらず、常に見やすい明るい画面で作業できます。ツールバーの色ボタンにも現在の選択色がそのまま表示されます。
- 多彩な線とマーカー: 直線、矢印、両矢印、曲線（フリーハンド）、半透明の蛍光ペン（マーカー）を描けます。線の種類もメニューや右クリックから「実線」「破線」「点線」に切り替えられます。
- 豊富な図形・目隠し・連番スタンプ: 四角、角丸四角、丸/楕円、三角に加えて、個人情報などを隠せる「モザイク（目隠し）」や、手順書作成に便利な「連番スタンプ（1, 2, 3...）」を配置できます。
- 自由自在な色と塗りつぶし設定: 「線/枠色」「文字色」「背景/塗色」を個別に設定でき、塗りつぶしは「透過（枠のみ）」「塗りつぶし」「半透明塗り」の3種類から選べます。
- 直感的なテキスト入力・編集: 文字を入力したあと、マウスを動かして好きな場所で左クリックするだけで配置できます。配置した文字をダブルクリックすると、いつでも内容を書き直せます。フォントや太字・斜体の変更にも対応しています。
- 複数ページのPDFに完全対応: PDFファイルを開いてページを切り替えながら全ページに注釈を書き込め、元のページ構成を保ったまま1つのPDFとして保存できます。
- スクリーンショット連携・ドラッグ＆ドロップ: 画像やPDFをウィンドウへドラッグ＆ドロップするだけで開けます。スクリーンショットを撮ったあと、アプリ上で Ctrl+V（または「ファイル」→「クリップボードから新規作成」）を押せばそのまま編集でき、完成した画像も Ctrl+Shift+C でメールや資料へすぐ貼り付けられます。
- 白紙キャンバス作成・画像回転・補助グリッド: ゼロから白紙キャンバスを作成したり、縦横が逆になった写真を90度回転させたり、位置合わせ用の補助グリッドを表示したりできます。
- ドラッグで余白調整: ツールバーの「⏹️ 余白調整(ドラッグ)」を選ぶと、画像の周囲に青いバーが表示されます。外側にドラッグすると余白を広げられ、広げた余白は内側にドラッグして削れます（元画像自体は誤って削られないよう保護されます）。余白を広げる色は「背景/塗色」で「塗りつぶし」を選ぶと反映されます。
- やり直し・プロジェクト保存: 「戻る」（Ctrl+Z）や「進む」（Ctrl+Y）で何度でもやり直せます。「プロジェクト保存（.hwi）」を使えば、注釈を動かせる状態のまま保存して後日続きから編集できます。

## 動作環境

- Windows 10 / Windows 11（64ビット版）

## インストール・実行方法

特別なインストール作業は不要です。

1. 配布された HandwrittenImageMiya-v1.6.0.exe をパソコンの分かりやすいフォルダに保存します。
2. HandwrittenImageMiya-v1.6.0.exe をダブルクリックして起動します。

### 初回起動時に警告画面が表示される場合

Windowsの保護機能（Windows Defender SmartScreen）により、「WindowsによってPCが保護されました」という青い警告画面が表示されることがあります。これは未登録のアプリを初めて起動する際に出る標準のメッセージです。以下の手順でそのまま安全に起動できます。

1. 画面内の「詳細情報」をクリックします。
2. 右下に表示される「実行」ボタンをクリックすると、アプリが起動します。

※ 一度実行すると、2回目以降は警告が表示されなくなります。

## 基本的な使い方

1. ファイルを開く: 「📂 開く」ボタンを押すか、画像・PDFファイルをアプリ画面へドラッグ＆ドロップします。白紙から始めたいときは「ファイル」→「新規キャンバス作成」を選びます。
2. 注釈を描く: ツールバーから「線」「図形」「文字」などのツールを選び、画面上をドラッグまたはクリックして配置します。
   - Shiftキーを押しながらドラッグすると、直線や矢印を水平・垂直・45度に揃えたり、図形をきれいな正方形・正円にしたりできます。
   - 「モザイク（目隠し）」は、隠したい範囲を四角くドラッグするだけで自動的にモザイクがかかります。
   - 「連番スタンプ」は、番号を振りたい場所をクリックするだけで 1, 2, 3... と順番に丸数字を配置できます。
3. 移動・修正する: 「↖️ 選択/移動」ツールを選ぶと、描いた図形や文字をドラッグで動かしたり、青い四角ハンドルを引っ張って大きさを変えたりできます。文字やスタンプはダブルクリックで内容を書き換えられます。右クリックメニューからは、最前面・最背面への移動、線スタイルの変更、挿入画像の縦横比リセットなどができます。
4. 画面を拡大・移動する: Ctrlキーを押しながらマウスホイールを回すと、マウスカーソルの位置を中心に拡大・縮小できます。拡大中に画面を動かしたいときは、スペースキーを押しながらドラッグ（またはマウスの中ボタンドラッグ）するとスムーズに動かせます。
5. 保存・共有する:
   - 「💾 保存」（Ctrl+S）で上書き保存、「💾 名前を付けて保存」（Ctrl+Shift+S）で JPG / PNG / PDF として書き出せます。
   - 後から文字や図形を修正したい場合は、「📦 プロジェクト保存」（Ctrl+P）で .hwi ファイルとして保存してください。
   - チャットや文書にそのまま貼りたいときは、「ファイル」→「完成画像をクリップボードにコピー」（Ctrl+Shift+C）が便利です。
